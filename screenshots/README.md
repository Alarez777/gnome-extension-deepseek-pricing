# Screenshots for extensions.gnome.org

Drop the screenshots for the extension listing here:

- `panel.png` — top bar with the whale icon and the countdown.
- `menu.png` — popup open, showing status, countdown, timeline and prices.

Recommendations from EGO:

- PNG, around 1920×1080 (16:9).
- Clean background, no personal data (file names, notifications, email, accounts).
- Extension UI in the foreground; avoid overlapping windows.
- Spanish and/or English UI, matching the README language selector.
